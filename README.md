# StockMate

StockMate is a browser-based inventory management application for small shops and businesses. It helps users organize products, update stock, monitor inventory, and identify products that are running low.


## Project Status
StockMate is a fictional product used for technical documentation.  

## Tools Used  
- **OpenAI Codex**: helped create rough drafts of the documentation.
- **Visual Studio Code (VS Code)**: used to write and edit the documents.
-  **Markdown**: used to format the documentation.
-  **GitHub**: used to host and share the project

## Features
- Add, edit, and remove product records.
- Update stock quantities when products arrive or leave inventory.
- View inventory from a central dashboard.
- Search and filter products.
- Set minimum stock levels and receive notifications when products are low.

## Requirements  
- A registered StockMate account.
- An internet connection.
- A supported web browser on a computer, laptop, or tablet.

## Getting Started
StockMate is accessed through a web browser. Create or use an existing business account, sign in, then add products and their current stock quantities. Set minimum stock levels for products you wish to be notified about.
